# تصمیم‌ها و فرض‌ها

- بدون کتابخونه‌ی اضافه: مسیریابی hash ساده، PWA دستی (`public/sw.js`)، فونت Vazirmatn خودمیزبان (OFL).
- رنگ برند: چون پروژه‌ی قبلی/پالتی وجود نداشت، یک زعفرانی-گوجه‌ای گرم (`--brand`) در `tokens.css` انتخاب شد. تغییرش فقط یک متغیره.
- تایمر: `endsAt` مطلق ذخیره می‌شه و باقی‌مانده از ساعت محاسبه می‌شه (نه ذخیره).
- شروع آشپزی برای غذای دیگه، جلسه‌ی قبلی رو جایگزین می‌کنه؛ برای همون غذا ادامه می‌ده.
- مواد پایه (نمک، روغن، فلفل، زردچوبه) و وسایل تابه/قابلمه در ابتدا «دارم» هستن؛ کاربر می‌تونه عوض کنه.
- هنوز نیست: ویرایش دستورها/نقش مدیر، قیمت واقعی، تاریخ شمسی (تاریخچه‌ی پخت فقط ذخیره می‌شه، جایی نشون داده نمی‌شه).
