# مرز سرور (برای بعداً)

الان هیچ سروری نیست. تنها نقطه‌ای که می‌دونه داده کجاست `src/lib/gateway.js` است (`load`, `save`, `now`).

اگه بعداً سرور اضافه شد، این‌ها باید سمت سرور برن:

| موضوع | الان | بعداً |
| --- | --- | --- |
| دستورها، مواد، قیمت‌ها | seed داخل برنامه | API + پنل مدیر محتوا (نقش «مدیر محتوا») |
| قیمت واقعی مواد | نمونه | به‌روزرسانی دوره‌ای سمت سرور |
| علاقه‌مندی، مواد من، وسایل، تعداد نفرات | localStorage مهمان | حساب کاربری + همگام‌سازی |
| تاریخچه‌ی پخت | localStorage | حساب کاربری |
| احراز هویت | ندارد | ورود/ثبت‌نام + ادغام داده‌ی مهمان |

نکته: `gateway.load()` الان همگام (sync) است؛ با سرور باید async بشه و `AppProvider` یک حالت بارگذاری اولیه بگیره.
